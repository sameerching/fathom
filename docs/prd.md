# Fathom Product Requirements (Phase 1)

## Product Vision
Fathom helps people understand their complete financial picture in one place by bringing together income, spending, liabilities, investments, and net worth trends.

## MVP Scope (Phase 1 Foundation)
- Monorepo setup for backend and frontend services.
- Spring Boot backend foundation with PostgreSQL connectivity configuration.
- Health check API for environment validation.
- Next.js frontend shell with a simple landing page and navigation placeholders.
- Local development environment via Docker Compose for PostgreSQL.
- Initial project documentation for architecture and execution.

## Out of Scope (Phase 1)
- Authentication and user session management.
- Real bank integrations and account linking.
- Upload pipelines for transaction files.
- Investment valuation logic and market data ingestion.
- Liability amortization calculations.
- Net worth and cash flow calculation engines.
- Credential storage for external providers.
